# 📝 Todo List App

A simple Todo List App built with Flutter as a practice project. This app helps users manage their daily tasks by adding, completing, and deleting tasks. It uses Hive for local data storage to keep tasks saved on the device.

## ✨ Features

- Add new tasks
- Mark tasks as completed using a checkbox
- Display a strikethrough effect on completed tasks
- Delete tasks by swiping using the Slidable widget
- Store tasks locally using Hive

## 🛠️ Built With

- **Flutter** – UI development
- **Dart** – Programming language
- **Hive** – Local data storage
  
## 🎯 Purpose

This project was created as a practice project while learning Flutter. It helped me understand task management, handling user interactions, using Flutter widgets, and implementing local data persistence with Hive.
